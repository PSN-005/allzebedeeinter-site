# Security Policy

## Reporting a Vulnerability

If you discover a security issue related to this website or Zebedee Enterprise LLC public web assets, please report it privately.

Please do not open a public GitHub issue for security-sensitive reports.

Contact:

info@allzebedeeinter.biz

Please include:

- A short description of the issue
- The affected page or file, if known
- Steps to reproduce, if applicable
- Any relevant screenshots or details

We will review reports as soon as reasonably possible.

## Scope

This policy applies to the public website repository only.

This repository is for public website content. It should not contain private client data, private reports, tested domains, credentials, API keys, private remediation notes, or confidential business information.

## Privacy

Zebedee Enterprise LLC treats security reports and client-related information carefully.

Client domains, reports, internal working notes, remediation details, and private business information should remain private unless explicitly approved for sharing.

## Public Issues

Please do not submit security-sensitive information through public GitHub issues, pull requests, or discussions.
